## 实时离线实验

先运行 `node lab-build.mjs`，只读原项目源码并用本机JDK 17和缓存依赖编译至本工具lab-cache目录；无需Maven、Spring或数据库。再运行 `node build.mjs` 和 `node server.mjs`，打开 http://127.0.0.1:5186/ 。如果旧服务已在运行，需要先正常关闭旧服务，再启动新版；不要对着旧页面排查新功能。

每次统一覆盖18条合成查询的最大距离和可用分钟数，其余画像、状态、预算、位置、时刻和原分组保留原值。三策略和原推荐引擎均复用原Java实现，公平计数每次从零开始，按原分组隔离。输入节点没有改成真实地点，旧分组名也不再说明当前距离范围。

服务只监听127.0.0.1:5186，拒绝其他Host和跨站Origin，仅接收最大2048字节的四参数JSON。并发1，不排队、不自动重试；Java限制128MB、10秒、16KB标准输出。运行前比较源码、字节码、输入模板和依赖清单校验和，发现变化就要求重编译。每次新建lab-runs目录，最多保留100个运行目录后停止新运行，需人工归档；不会自动删除旧记录。

网页的运行按钮只向固定同源接口发送四个合成配置数字，不发送采集文件或个人位置。请求及JSON读取共用15秒截止时间，截止后恢复按钮并忽略晚到结果；不自动重试实验。请求失败、参数变化或返回上下文不一致时隐藏旧结果，同时清除旧回放选择。Java结束后再次核对输入、报告、源码和字节码与该次构建的绑定。运行目录保留原始input.json、report.json和manifest.json。网页下载的是数据副本；界面显示的校验和对应运行目录中的原始文件。
