- 坐标转换：高德 status=1、info=ok。
- 周边搜索：高德 status=1、info=OK；固定餐饮分类 050000、distance 排序。
- WGS84 请求经过转换后 API HTTP 200、status=SUCCESS、坐标类型 GCJ02、距离类型 STRAIGHT_LINE。
- 用转换结果作为 GCJ02 输入，仍返回相同 10 个地点。

| 搜索半径 | API 状态 | 返回数 | 直线距离 |

| 3000 米 | 200 SUCCESS | 10（首批上限，不是区域总数） | 70–122 米 |
| 100 米 | 200 SUCCESS | 7 | 70–95 米 |

前三个真实结果：一品香川味涮牛肚（劳动路总店）70 米、广东海鲜大排档（劳动路店）71 米、石和记羊汤烩面（平顶山一分店）79 米。

## 字段与距离对账

10 条都有 poiId、name、type、typeCode、address、经纬度、distanceMeters、rating、tags；人均 9/10、营业时间 8/10、电话 8/10、可用 HTTPS 图片 6/10。该比例仅代表本次样本，不保证以后稳定存在。

高德原始响应与 DTO 逐 ID 对照：统一六位小数搜索中心后，10 条 distance 全部一致。最初直连查询保留了转换接口更多小数位，导致一条距离相差 1 米；统一为后端实际六位精度后消失，不是 DTO 计算错误。distance 是上游直线距离，不等于实际步行路线距离。

缺人均/营业文本/电话均返回 null，没有填 0 或推测。4 条图片只有 HTTP，安全过滤后 imageUrl=null；其他条目可以跳过前面的 HTTP 图片选取后面的 HTTPS 图片。真实样本未遇到 photos 整体缺失，该分支由模拟测试覆盖。

真实分类包含茶馆、快餐、中餐及其他餐饮；typeCode 可能是 `050121|050117` 多分类串，tags 可能含很长的逗号分隔菜名。前端后续不能假定分类都是单值、标签都很短，也不能把全部结果都称为饭店。

## 异常验证范围

- 权限：没有改动配置中的有效 Key；用明确无效的测试字符串直连高德，真实返回 status=0、infocode=10001、info=INVALID_USER_KEY。后端 AMAP_PERMISSION_DENIED 映射由受控测试验证；没有在运行环境替换 Key。
- 额度/频率：密集联调自然发生一次后端 HTTP 503，安全日志记录额度/频率分类，随后恢复成功。没有保留上游原始 infocode，因此不声称确认是哪一种额度；未耗尽每日额度。各额度码由模拟响应测试覆盖。
- 网络：本次真实服务未发生网络故障。通过本地测试服务器关闭连接验证 AMAP_NETWORK_ERROR 和敏感信息不外泄；没有断开运行中容器网络。
- 无结果：1 米半径真实返回 HTTP 200、NO_RESULTS、空数组。
- UNKNOWN 坐标：真实 API 返回 400，不继续搜索。
