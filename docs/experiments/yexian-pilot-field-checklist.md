## 5. 进入离线实验的门槛

1. 去重和场所范围明确：县衙在前一份平顶山证据表中对应 PDS-C09，不新增重复实体；叶公古街和明清街的关系未确认前，不合并别名，也不把两者视为两个已核验候选。
2. 每个实验坐标有明确来源、坐标系和点位角色；硬距离过滤使用一致语义，不以当前这份相机坐标或地址推算值替代。
3. 人工属性依照 [既有标注规范](pingdingshan-cultural-annotation-v1.md) 完成，并保留证据和分歧。未知不等于 0 分，也不等于全天开放、免费或没有体力消耗。
4. 长尾分组有与实验输出独立的依据。“近 500 摊”“某天很热闹”、静态小众标签和算法本身的入选次数，都不能直接当统一的人气真值。
5. 三处场所足以试采集流程，但如果每轮恰好只有三个有效候选且全部展示 Top3，就难以检验公平重排序的选择效果。后续须补充真实且独立的候选及合理实验场景，不能拆县衙内部展厅凑数量。
6. 完成上述门槛后才另行生成 `OfflineExperimentInput`，记录版本与来源。模拟入选次数仍不等于用户真实曝光，不对外宣称已验证真实公平收益。

叶邑故城、龙泉古桥、保安古城等可留在县域后续核查池；本轮不把它们加入未验证的老城步行线路，也不补造距离、开放情况和文化属性。
